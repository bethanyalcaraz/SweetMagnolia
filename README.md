# Sweet Magnolia

Mock-up website for **Sweet Magnolia**, a family pop-up selling homemade, bakery-sized oatmeal cream pies — seed-oil free, with marshmallow cream made from scratch.

Open `index.html` in a browser (no build step). It includes:

- Menu with add-to-cart steppers (prices are sample prices)
- Online order form: pickup at the tent or local delivery, date/time window, gift notes, and an order confirmation (demo only — nothing is charged or sent)
- Ingredients, family story, "find the pink tent" schedule, and FAQ
- Light and dark mode, mobile friendly

To host it for free, enable GitHub Pages on this repo (Settings → Pages → deploy from branch).
